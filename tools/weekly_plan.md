## Daily rhythm
- **Mon:** create repo, problem statement, data dictionary, data generation or download, data-quality pipeline.
- **Tue:** EDA and first findings.
- **Wed:** SQL deep-dive.
- **Thu:** core method (test, model or forecast) with proper validation.
- **Fri:** dashboard.
- **Sat:** ₹ impact sizing, recommendations report, case-study page on the portfolio.
- **Sun:** final README, LEARNING.md interview Q&A, fresh-clone check, results post draft.
